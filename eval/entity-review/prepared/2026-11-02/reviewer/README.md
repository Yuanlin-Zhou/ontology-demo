# 领域评审包

仅阅读本目录中的任务、源码、知识目录与原文档。请不要查看同级 engine/ 的预测或运行引擎后再填写；若已经看到预测，请如实声明，不能作为盲于预测的独立基线。知识指南也是 Agent 草案，需要领域确认。

把 annotations.template.json 复制到本目录之外填写。每个任务对全部叶子标 required / helpful / irrelevant / uncertain，并写依据；required / helpful 需关联本任务公开实体列表中的证据实体。不确定不能当作无关。引擎特征、标签和召回结果不包含在本包。身份与独立性声明只记录，不构成身份认证。
