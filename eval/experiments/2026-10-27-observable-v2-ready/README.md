本轮新增模型调用 0。7 个有明确回调的业务边界及其参考实现完成真实 Java 验证；完整测试 144 项通过、0 失败、0 跳过。额外的定向测试确认：契约版本从 manifest 推断，显式版本不一致会取消受控实验标记。source_revision 与参考源码 SHA-256 见 metadata.json。

## 完成内容

- 通知、同步、导出、日志、库存、文件处理、实时推送通过可注入 Consumer 观测真实业务效果；同步还使用 Function 提供实际查询结果。
- 验收覆盖原始参数、异步调度、失败隔离、后续交付、计数与实际效果一致、饱和拒绝、SKU 补偿、租户上下文恢复、关闭等待、无参未配置显式失败与公开配置构造拒绝 null。
- 反例确认：空业务回调但仅增加计数、在调用线程直接执行业务、拒绝计数不变、租户不清理均被阻止。
- 优先级回归增加“最低优先级中错误淘汰最新任务”的反例；已有正反例同时覆盖最高优先级误删、扩容绕过准入、取消内层任务但排队外层对象、关闭不完成等待方与无法终止却正常返回。参考实现的正确行为不等于模型生成效果已经改善。
- 队列与关闭规则说明补充初始容量不等于上限、最低优先级中最旧的选择顺序、遍历不能错误 break，以及关闭失败与重复 stop 的要求。静态检查器并未因此获得通用数据流正确性证明。

## 限制与后续
